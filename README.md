# release-please-templates

> Automated releases and changelogs, preconfigured per language.

**Status:** 🚧 In development

## Overview

Curated release-please setups for multi-language automated versioning and changelogs.

## Features

- Ready configs for Go, Python, Terraform module, and monorepo
- Conventional-commits changelog sections
- Tag + GitHub Release automation
- Manifest-driven multi-package setup
- Example workflows and PR flow docs

## Stack

GitHub Actions + release-please.
